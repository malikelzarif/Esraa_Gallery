Important Checkout Notes

Static site order handling

No direct card processing

This website should never collect credit card numbers directly. Stripe, PayPal, Venmo, or Zelle should be handled through external links or manual instructions.

Order request only

Because this is HTML, CSS, and JavaScript only, the checkout form stores the order summary in localStorage and shows confirmation on screen.

Future email connection

To receive real customer orders by email, connect the form later to Formspree, EmailJS, Netlify Forms, or a custom backend.

Custom order confirmation

Custom handmade orders should be confirmed before production begins, especially for colors, names, themes, deadlines, and pricing.
